# Frontend Development Skill

## Purpose
Deliver clear, accessible interfaces that match approved CrossLife workflows.

## Workflow
1. Inspect the existing design system, routing, state and component conventions.
2. Identify the user, task, permission and relevant states.
3. Design loading, empty, success, validation, error and forbidden states.
4. Implement accessible forms and navigation.
5. Validate client input for usability while relying on server validation for security.
6. Test responsive behaviour and role-specific visibility.
7. Verify that UI restrictions align with backend authorisation.

## Rules
Do not invent workflows or fields. Avoid generic dashboard clutter. Use CrossLife terminology. Never rely on hidden buttons as the only access control.
