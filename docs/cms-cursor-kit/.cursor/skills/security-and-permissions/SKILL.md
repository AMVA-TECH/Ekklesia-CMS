# Security and Permissions Skill

## Purpose
Translate actual duties and data sensitivity into enforceable access rules.

## Workflow
1. Identify assets, actors, trust boundaries and threats.
2. Classify data and determine who needs access and why.
3. Separate authentication, role assignment, permission and record scope.
4. Define allow/deny rules and exceptional access.
5. Enforce authorisation on every backend operation.
6. Audit high-impact access and changes.
7. Test horizontal and vertical privilege escalation, direct API access and object-level access.
8. Review logging, exports, attachments, backups and retention.

## CrossLife cautions
Public leadership titles do not automatically confer software access. Reporting relationships do not automatically grant financial or pastoral access. Treat pastoral, children's and financial information as high sensitivity. Escalate legal interpretations for qualified review.
