# Tasks and Backlog

**Status:** Initial planning backlog. Items are not automatically approved development tasks.

## P0 — Project setup and discovery

- [ ] Confirm project sponsor and authorised business decision-maker.
- [ ] Confirm the actual current church operating model and validate the published leadership baseline.
- [ ] Identify process owners for people/membership, ministries, services and finance.
- [ ] Inventory current registers, spreadsheets, forms and tools.
- [ ] Map people and membership AS-IS workflow.
- [ ] Map visitor/newcomer handling, if applicable.
- [ ] Map ministry participation and leadership assignment workflows.
- [ ] Map service/event planning and attendance.
- [ ] Assess communication needs.
- [ ] Discover finance and stewardship workflows; decide whether finance belongs in MVP.
- [ ] Identify personal/sensitive data, access needs and retention expectations.
- [ ] Draft Product BRD and CrossLife Pilot BRD.
- [ ] Prioritise and obtain approval for MVP requirements.

## P1 — Repository and technical assessment

- [ ] Inspect existing repository and document current stack.
- [ ] Identify current application structure and coding conventions.
- [ ] Identify deployment environments and operational constraints.
- [ ] Review existing authentication and authorisation implementation, if any.
- [ ] Review current data model and migration strategy, if any.
- [ ] Produce architecture decision records for material choices.

## P2 — Implementation (blocked until relevant requirements are approved)

- [ ] Implement foundation according to approved architecture.
- [ ] Implement approved people and membership workflows.
- [ ] Implement only approved church operations modules.
- [ ] Implement finance only if approved and controls are specified.
- [ ] Complete role-based and negative-permission tests.
- [ ] Prepare data migration and UAT.

## Backlog hygiene

Every implementation task must link to:
- Requirement ID(s).
- User/business outcome.
- Acceptance criteria.
- Dependencies.
- Security/privacy impact.
- Test evidence.
- Status and owner.
