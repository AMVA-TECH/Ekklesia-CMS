# Ekklesia branding assets

Production logo system traced from the approved fish + cross mark (identical geometry for dark and light).

| File | Use |
|---|---|
| `ekklesia-symbol-dark.svg` | Transparent symbol on dark surfaces |
| `ekklesia-symbol-light.svg` | Transparent symbol on light surfaces |
| `ekklesia-horizontal-dark.svg` | Symbol + wordmark lockup on dark |
| `ekklesia-horizontal-light.svg` | Symbol + wordmark lockup on light |
| `ekklesia-logo-dark.svg` | Squircle app icon (dark tile) |
| `ekklesia-logo-light.svg` | Squircle app icon (light tile) |
| `favicon.svg` | Browser favicon (simplified stroke) |
| `favicon-16/32/48.png` | Raster favicons |
| `icon-192.png` / `icon-512.png` | PWA / install icons |
| `apple-touch-icon.png` | iOS home-screen icon |

Product UI should use `<BrandMark>` from `_ekklesia/ui` so light/dark selection stays centralized.

Do not redesign geometry. Do not embed the source raster photos inside SVG files.
